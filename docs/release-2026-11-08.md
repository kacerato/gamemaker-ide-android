# GM IDE Android 0.2.0 — 08/11/2026

Publicação do código local completo e atualização do APK com os ajustes atuais
de preview, exportação e interação mobile descritos nos documentos do projeto.

## Identidade e pacote

- Nome no launcher e na instalação: **GM IDE Android**.
- Arquivo: `gmide-android-2026.11.08-release.apk`.
- Pacote preservado: `io.gmide.android`.
- Versão: `0.2.0`, versionCode `2`.
- Ícone adaptativo vetorial, com variante monocromática no Android 13+.
- ABI ARM64; instalação a partir do Android 8, preview local a partir do Android 11.

## Verificação desta publicação

As classes Java foram recompiladas antes do host .NET em **Release**, com
`AndroidDebuggable=false`. A compilação terminou com **0 erros e 10 avisos**,
relacionados a nulabilidade, marshaling, APIs de assemblies/trimming e Java 8.
O manifesto empacotado foi conferido: nome, versão, ícone, ARM64 e ausência de
`debuggable`. A assinatura APK v2/v3 foi validada com `apksigner`.

O certificado coincide com o release de 07/11, permitindo atualização com a mesma
assinatura. O nome do certificado é `Android Debug`; ele não define a configuração
de compilação do aplicativo. Esta publicação preserva essa identidade de assinatura.

## Aceite no aparelho

1. Instalar por cima, preservando dados e projetos; conferir nome e ícone.
2. Abrir o projeto e conferir recursos, arquivos e preferências preservados.
3. Editar código com o teclado, rolar listas e abrir os diálogos de importação.
4. Executar F5, parar e executar novamente; conferir F6/PiP quando disponível.
5. Gerar um APK Android VM e abrir o jogo resultante.

O pacote base `gmide-package.zip` mantém a IDE/runtime original; ele é necessário
na primeira instalação e não precisa ser importado novamente em atualizações normais.
